# H - getters_menu

Printing the return value of a function instead of a variable.

**Demonstrates:** passing a getter function to a `LiquidLine` instead of a
variable, getters returning a number and getters returning `const char*`.

**Hardware:** Arduino Uno/Nano, HD44780 16x2 display, 10k potentiometer for the
contrast and a second one on A1.

**Simulate:** [`diagram.json`](diagram.json) - see
[Simulating the examples](../../README.md#simulating-the-examples-with-wokwi).
