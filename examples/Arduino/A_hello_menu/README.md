# A - hello_menu

The "get started" example: a menu of two screens, the second one showing a
variable that changes while the sketch runs.

**Demonstrates:** `LiquidLine`, `LiquidScreen` and `LiquidMenu`,
`LiquidMenu::add_screen()`, `LiquidMenu::update()`, `LiquidMenu::next_screen()`,
printing a live variable.

**Hardware:** Arduino Uno/Nano, HD44780 16x2 display wired in 4-bit parallel
mode, a 10k potentiometer for the contrast and (optionally) a second one on A1.

**Simulate:** [`diagram.json`](diagram.json) - see
[Simulating the examples](../../README.md#simulating-the-examples-with-wokwi).
