# E - focus_menu

Customizing the focus (selection) indicator: where it appears and what it looks
like.

**Demonstrates:** `set_focusPosition()` per line (`LEFT`, `RIGHT`, `CUSTOM`) and
per screen, `LiquidMenu::set_focusSymbol()` with a hand-drawn 5x8 character.

**Hardware:** Arduino Uno/Nano, HD44780 16x2 display, 10k potentiometer for the
contrast, three push-buttons to ground (LEFT A0, RIGHT 7, ENTER 10).

**Try it:** RIGHT/LEFT change the screen, ENTER moves the focus.

**Simulate:** [`diagram.json`](diagram.json) - see
[Simulating the examples](../../README.md#simulating-the-examples-with-wokwi).
