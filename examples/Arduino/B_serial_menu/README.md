# B - serial_menu

Drives the menu from the Serial Monitor, so you can try every navigation
method without wiring a single button.

**Demonstrates:** `next_screen()` / `previous_screen()`, `switch_focus()`,
`call_function()`, `set_focusPosition()`, reusing one `LiquidLine` on several
screens.

**Hardware:** Arduino Uno/Nano, HD44780 16x2 display, 10k potentiometer for the
contrast. Open the Serial Monitor at 250000 baud and type one of the printed
commands.

**Simulate:** [`diagram.json`](diagram.json) - see
[Simulating the examples](../../README.md#simulating-the-examples-with-wokwi).
